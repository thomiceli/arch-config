# arch-config

Arch + Hyprland + Noctalia desktop config, managed with [GNU Stow](https://www.gnu.org/software/stow/).

The repo mirrors `$HOME`: dotfiles at the root, app configs in `.config/`.
`stow .` links everything except `system/` and the files in `.stow-local-ignore`.

## Install on a new machine

```sh
sudo pacman -S --needed git stow
git clone git@github.com:thomiceli/arch-config.git ~/arch-config
cd ~/arch-config

# packages
sudo pacman -S --needed - < system/pkglist.txt
yay -S --needed - < system/pkglist-aur.txt

# dotfiles (remove/rename any existing conflicting files first)
stow -t ~ .

# system files (NVIDIA modules in mkinitcpio, nvidia_drm.modeset=1 in grub,
# uwsm autostart in /etc/profile, greetd -> noctalia greeter)
sudo cp -r system/etc/. /etc/
sudo mkinitcpio -P
sudo grub-mkconfig -o /boot/grub/grub.cfg
chsh -s /usr/bin/zsh

# services
xargs sudo systemctl enable < system/services.txt
xargs systemctl --user enable < system/user-services.txt
```

Then:
- tmux plugins (tpm, tmux-sensible, rose-pine/tmux) are managed by tpm, which must be cloned first:
  ```sh
  git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
  ```
  Then start tmux and press `prefix + I` to install the rest.
- zsh: `fzf-tab` is cloned automatically into `~/.local/share/zsh/fzf-tab` on the first shell launch.
- Noctalia plugins are listed in `.config/noctalia/plugins.json` and get reinstalled by Noctalia.
- `.config/hypr/noctalia/noctalia-colors.conf` is generated by Noctalia, so Hyprland may complain about it until Noctalia has run once.

## Updating

Most configs are symlinked directories, so edits land in the repo directly — just commit.

`system/` is copied, not linked. Refresh it with:

```sh
pacman -Qqen > system/pkglist.txt
pacman -Qqem > system/pkglist-aur.txt
cp /etc/greetd/config.toml system/etc/greetd/
cp /etc/mkinitcpio.conf /etc/profile system/etc/
cp /etc/default/grub system/etc/default/
```
